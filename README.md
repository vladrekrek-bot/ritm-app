# RITM

Режим дня, питание, тренировки и прогресс. Один код (`www/index.html`) — работает в браузере на ПК и как приложение на iPhone.

## Как получить .ipa для ESign
1. Любой push в ветку `main` запускает сборку (вкладка **Actions**). Можно запустить и вручную: Actions → «Собрать IPA для ESign» → Run workflow.
2. Через ~5–10 минут во вкладке **Releases** появится `RITM.ipa`.
3. На iPhone открой Releases в Safari → нажми `RITM.ipa` → «Открыть в ESign» → подписать своим сертификатом → установить.

## Как обновить приложение
Меняешь `www/index.html` → push → новый `.ipa` в Releases → ставишь поверх в ESign. Данные сохраняются, если bundle id тот же.
